🏦 Loan Approval Prediction

A Machine Learning project that predicts loan approval outcomes using classification algorithms.

📌 Overview

Loan approval is an important decision-making process in the banking and financial industry. This project uses Machine Learning techniques to analyze applicant information and predict whether a loan application will be approved or rejected.

🎯 Objectives

* Analyze loan applicant data.
* Perform data cleaning and preprocessing.
* Explore relationships between different features.
* Apply Machine Learning classification algorithms.
* Evaluate and compare model performance.

🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

📊 Data Analysis & Preprocessing

* Data Cleaning
* Handling Missing Values
* Exploratory Data Analysis (EDA)
* Data Encoding
* Correlation Analysis
* Feature Scaling
* Feature Engineering

🤖 Machine Learning Algorithms

The following classification algorithms are implemented:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Gaussian Naive Bayes

📈 Model Evaluation

Model performance is evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

⚙️ Feature Engineering

Additional features are created using squared transformations of:

* DTI Ratio
* Credit Score
